Configuration Supabase

Avant la première utilisation, ajoute l’URL du projet et la clé anon/publishable dans config.js. Ne mets JAMAIS une clé service_role dans le navigateur.

Si Supabase n’est pas configuré, la connexion admin ne sera pas disponible.

Pour publier le site, modifie aussi le fichier config.js avant l’hébergement.

Connexion administrateur

Connecte-toi avec un compte créé dans Supabase Authentication. Seuls les comptes autorisés par les règles de sécurité peuvent modifier le menu.

Tu es dans l’espace d’administration. Les changements enregistrés ici sont stockés dans la base Supabase et seront visibles sur le menu public. L’accès en écriture doit être limité à ton compte avec les politiques SQL fournies.
